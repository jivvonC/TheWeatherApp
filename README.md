<h2>📄 Project Description</h2>
<p>
The Weather App allows users to search locations using the Kakao Map API and save them to check real-time weather based on their stored locations.
It provides a simple and intuitive way to view localized weather information.
</p>

<h2>✨ Features</h2>
<ul>
  <li>Session-based login</li>
  <li>Kakao Map API integration for location search</li>
  <li>Save locations and view real-time weather for each saved area</li>
</ul>
